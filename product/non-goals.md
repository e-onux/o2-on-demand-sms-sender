# Non-Goals

Explicitly out of scope - at the product level. The agent treats these like a project-wide `does_not`: features
here require a deliberate, human-approved scope change before any implementation.

- Bypassing O2 billing, authentication, quotas or paid services.
- Sending arbitrary bulk SMS or acting as a general messaging client.
- Managing modem settings unrelated to data-renewal automation.
- Remote multi-user administration, cloud synchronization or telemetry.
- Storing complete, unbounded SMS or event archives.
- Replacing Docker Desktop, the host operating system's startup manager or platform security prompts.
